## 📖 Sobre o projeto

A **Biblioteca Musical** é uma aplicação web desenvolvida com o objetivo de representar um sistema de organização de um catálogo musical. A interface reúne telas de acesso, navegação, cadastro de artistas, cadastro de músicas e consulta das obras cadastradas.

## ✨ Funcionalidades e telas

| Tela | Arquivo | Descrição |
|:--|:--|:--|
| 🔐 Login | `login.html` | Tela de entrada demonstrativa |
| 🏠 Menu principal | `index.html` | Navegação pelas áreas do sistema |
| 🎤 Cadastro de artistas | `cadastro_artista.html` | Interface para cadastro de artistas |
| 🎼 Cadastro de músicas | `cadastro_musica.html` | Interface para cadastro de músicas |
| 📚 Catálogo musical | `listagem_musicas.html` | Visualização, busca e filtros do catálogo |

## 🎨 Identidade visual

O projeto utiliza uma folha de estilos compartilhada (`styles.css`) para manter a aparência consistente entre as páginas. As cores principais são organizadas na seção `:root`, facilitando futuras alterações na paleta e no tema visual.

## 📱 Layout responsivo

A interface foi estruturada para se adaptar a diferentes tamanhos de tela, utilizando recursos como **CSS Grid**, **Flexbox** e **media queries**. Em dispositivos menores, as tabelas podem ser visualizadas com rolagem horizontal.
