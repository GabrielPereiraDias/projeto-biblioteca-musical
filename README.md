# 🎵 Biblioteca Musical

Uma aplicação web de estudo para organizar uma biblioteca musical, reunindo cadastro de artistas, cadastro de músicas e visualização do catálogo em uma interface simples e responsiva.

## ✨ Telas do projeto

| Tela | Arquivo | Descrição |
|---|---|---|
| Login | `login.html` | Entrada demonstrativa do sistema |
| Menu principal | `index.html` | Acesso às funcionalidades |
| Cadastro do criador | `cadastro_artista.html` | Formulário e listagem de artistas |
| Cadastro da obra | `cadastro_musica.html` | Formulário e listagem de músicas |
| Listagem | `listagem_musicas.html` | Catálogo com campos de busca e filtros |

## 🎨 Identidade visual

Todas as telas utilizam um único arquivo `styles.css`. A paleta de cores fica centralizada em `:root`, facilitando a manutenção da identidade visual.

## 📱 Responsividade

O layout utiliza CSS Grid, Flexbox e media queries para se adaptar a computadores, tablets e celulares. As tabelas possuem rolagem horizontal em telas menores.

## 🔐 Acesso demonstrativo

- **Usuário:** `admin`
- **Senha:** `123`

O login é demonstrativo e funciona no navegador. Esta versão não possui autenticação em servidor nem banco de dados conectado; os formulários de cadastro também representam a interface visual do sistema.

## 🧰 Tecnologias

- HTML5
- CSS3
- JavaScript (validação demonstrativa do login)
